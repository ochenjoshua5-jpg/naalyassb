## Fact check: Privacy notice

The draft describes the preview honestly. It has no forms, no payments and no analytics, and fonts are served from the site itself. The legal basis cited is the Data Protection and Privacy Act, 2019 (enacted 1 March 2019), including its requirement for parent or guardian consent before a child’s personal data is processed.

Open items the school must confirm:

1. Legal name of the organisation responsible for personal data at the campus.
2. Privacy contact person, role and contact details.
3. Retention periods for enquiry and application records.
4. Hosting location. If data is processed outside Uganda, the notice must say so.
5. Child protection and safeguarding statement.
6. Whether any analytics or messaging tools will be added.

This draft is not legal advice.

## Libraries and patterns

The Day 3 brief suggested NextUI, DaisyUI, HeadlessUI, Starlight, Docusaurus, the Next.js blog starter, Payload, Cloudinary, react-leaflet and opensource.guide. The site keeps the brief’s stack (owned shadcn-style components on Radix), and adopts only the patterns:

| Reference | What was adopted |
| --- | --- |
| HeadlessUI (Disclosure, Tabs) | Accessible accordion and tabs, built on Radix (`@radix-ui/react-accordion`, `@radix-ui/react-tabs`) |
| DaisyUI (timeline, collapse, steps) | Timeline, collapse and stepper patterns in owned components |
| NextUI | Theming ideas only. Not added as a second component library, to keep the bundle small and the palette in one place. |
| Starlight | Sticky “on this page” navigation |
| Docusaurus | Structured metadata per item (source, status, owner), kept in `lib/content.ts` |
| Next.js blog starter | Layout for the news list and empty state |
| Payload CMS | Typed content models (`lib/content.ts`) with consent and approval fields, ready for a future CMS |
| opensource.guide | Chapter-style storytelling on the About page |
| Cloudinary | Not used. There are no approved photos and no account. Use optimised local images when approved. |
| react-leaflet | Not used. The coordinates are unverified. Add a map once the campus location is confirmed. |

Rejected from the Day 3 mapping: DaisyUI “stats” boxes, parent testimonials as chat bubbles, Nursery and Primary tabs, the “98% pass rate” and similar figures, and a contact form.
